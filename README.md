# Recipe API

A RESTful API built using Spring Boot and MongoDB to manage recipe data.

---

## Project Description

This application:

- Reads recipe data from a JSON file
- Stores data in MongoDB using batch insertion
- Provides REST endpoints to create and retrieve recipes
- Validates required fields
- Automatically calculates total_time (prep_time + cook_time)
- Prevents duplicate data loading on restart
